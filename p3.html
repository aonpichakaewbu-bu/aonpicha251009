รวมสูตรคณิตศาสตร์

เซตและการดำเนินการของเซต

  • n(A ∪ B) = n(A) + n(B) - n(A ∩ B)
  • A − B = {x ∈ A, x ∉ B}
  • A′ = U − A
  • A ∩ B = สมาชิกร่วม
  • A ∪ B = สมาชิกทั้งหมด
  • ∅ = เซตว่าง
  • U = เอกภพสัมพัทธ์

ตรรกศาสตร์เบื้องต้น

  • ~p = นิเสธของ p
  • p ∧ q = และ
  • p ∨ q = หรือ
  • p → q = ถ้า…แล้ว
  • p ↔ q = ก็ต่อเมื่อ
  • T = จริง
  • F = เท็จ

จำนวนจริง

  • a + b = b + a
  • ab = ba
  • (a + b) + c = a + (b + c)
  • (ab)c = a(bc)
  • a(b + c) = ab + ac
  • a + 0 = a
  • a × 1 = a

ค่าสัมบูรณ์

  • |a| = a เมื่อ a ≥ 0
  • |a| = -a เมื่อ a < 0
  • |a| ≥ 0 เสมอ
  • |-a| = |a|
  • |ab| = |a||b|
  • |a/b| = |a|/|b| เมื่อ b ≠ 0
  • |x| = a ⇒ x = ±a

ฟังก์ชัน

  • y = f(x)
  • โดเมน = ค่าของ x
  • เรนจ์ = ค่าของ y
  • f(a) = แทน x ด้วย a
  • ฟังก์ชันต้องมีผลลัพธ์เดียว
  • กราฟแสดงความสัมพันธ์
  • จุด (x, y) อยู่บนกราฟ

ฟังก์ชันเชิงเส้น

  • y = mx + b
  • m = (y₂ − y₁) / (x₂ − x₁)
  • b = จุดตัดแกน y
  • m > 0 กราฟเพิ่ม
  • m < 0 กราฟลด
  • m = 0 กราฟแนวนอน
  • กราฟเป็นเส้นตรง

เลขยกกำลัง

  • aᵐ × aⁿ = aᵐ⁺ⁿ
  • aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • (aᵐ)ⁿ = aᵐⁿ
  • (ab)ⁿ = aⁿbⁿ
  • a⁰ = 1
  • a⁻ⁿ = 1 / aⁿ
  • a¹ = a

ฟังก์ชันเอ็กซ์โพเนนเชียล

  • y = aˣ (เมื่อ a > 0 และ a ≠ 1)
  • y = a⁰ = 1 (ผ่านจุด (0,1))
  • a > 1 กราฟเพิ่ม
  • 0 < a < 1 กราฟลด

ลอการิทึม

  • logₐN = x ⇔ aˣ = N
  • logₐ1 = 0
  • logₐa = 1
  • logₐMN = logₐM + logₐN
  • logₐ(M/N) = logₐM − logₐN
  • logₐMⁿ = n logₐM

ลำดับเลขคณิต

  • a₁ = พจน์แรก, aₙ = พจน์ที่ n
  • d = ผลต่างร่วม (a₂ − a₁ = a₃ − a₂)
  • aₙ = a₁ + (n − 1)d
  • aₙ₊₁ = aₙ + d
  • d = (aₙ − a₁) / (n − 1)

ลำดับเรขาคณิต

  • a₁ = พจน์แรก, aₙ = พจน์ที่ n
  • r = อัตราส่วนร่วม (a₂ / a₁)
  • aₙ = a₁rⁿ⁻¹
  • aₙ₊₁ = aₙr
  • r คงที่ทุกพจน์ (aₙ / aₙ₋₁ = r)
